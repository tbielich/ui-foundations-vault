# Lessons

Lessons are extracted from concrete work and written so they can be reviewed, cited, and promoted.

## Lesson Shape

A lesson should include:

- Source issue, PR, experiment, review, or incident.
- Local fact observed.
- Generalized lesson.
- Affected repositories or domains.
- Proposed next action.
- Promotion candidate, if any.

## Promotion

Repeated lessons should be proposed as governance, specification, workflow, prompt, or export-pack updates.
