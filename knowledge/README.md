# Cross-Repo Knowledge

## Purpose

This area collects reusable knowledge that is discovered across UI Foundations repositories and is not yet necessarily a principle, governance rule, specification, workflow, or prompt.

Knowledge here should be easy to review, cite, and promote when repeated evidence proves it should become more authoritative.

## Navigation

- `components/`: reusable component findings and model notes.
- `tokens/`: reusable token findings and semantic token observations.
- `accessibility/`: accessibility findings that apply across repositories.
- `agentic/`: agent behavior and collaboration findings.
- `governance/`: governance candidates before promotion.
- `runtime/`: implementation-adjacent findings without runtime code.
- `lessons/`: extracted lessons from issues, PRs, experiments, and reviews.

## Promotion Path

Lessons may become:

- Governance when they define trust, review, ownership, or decision rules.
- Specifications when they define expected structure or behavior.
- Workflows when they define repeatable action.
- Prompts when they operationalize existing knowledge for agents.
