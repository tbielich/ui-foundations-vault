# Operational Knowledge

## Question

What is operational knowledge?

## Purpose

Operational knowledge explains how to apply existing foundations, UI Foundations knowledge, governance, and reference material in repeatable review situations.

Operational documents are informative playbooks. They do not create new principles, architecture, governance, or executable instructions.

## Inputs

- Existing vault documents
- A review topic
- Available evidence
- Open questions

## Preconditions

- The topic belongs in the vault or one of the related UI Foundations repositories.
- Relevant source documents have been identified.
- Reviewers understand the precedence model.

## Steps

1. Start from the relevant operational playbook.
2. Follow linked foundations, UI Foundations knowledge, governance, and reference documents.
3. Apply the playbook without redefining the source knowledge.
4. Record outputs in the appropriate document or review channel.

## Outputs

- Review findings
- Decisions to record elsewhere
- Follow-up questions
- Required document updates

## Quality Gates

- The playbook references source knowledge instead of restating it.
- The output distinguishes evidence, assumptions, and recommendations.
- No implementation or tool-specific behavior is introduced.
