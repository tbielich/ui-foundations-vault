# Accessibility Principles

## Question

How can everyone use the interface?

## Purpose

Accessibility ensures that people with different abilities, tools, environments, and constraints can perceive, understand, navigate, and use an experience.

## Principles

- Perceivable: information and controls must be available through more than one sensory path when possible.
- Operable: interactive experiences must support keyboard, pointer, touch, and assistive technology patterns where relevant.
- Understandable: language, structure, labels, and feedback should be predictable and clear.
- Robust: meaning and state should survive changes in device, browser, assistive technology, and presentation.
- Semantic: structure should communicate purpose, relationship, and state, not only appearance.
- Focused: current position and available action should be visible during navigation.
- Color-independent: color should reinforce meaning, not be the only way meaning is conveyed.
- Recoverable: people should be able to identify, understand, and correct errors.

## Guidance

Accessibility is not a final compliance pass. It is a design constraint that shapes structure, interaction, content, color, typography, and feedback from the beginning.
