# Color Theory

## Question

How should color communicate meaning?

## Purpose

Color supports meaning, hierarchy, emotion, and recognition. It must remain understandable under varied perception, context, and display conditions.

## Principles

- Contrast: foreground, background, boundaries, and states must remain distinguishable.
- Semantics: color should carry consistent meaning within a context.
- Status versus state: persistent meaning and temporary interaction feedback should not be confused.
- Redundancy: color should be paired with text, shape, position, or structure when it conveys important meaning.
- Restraint: fewer meaningful colors are stronger than many decorative colors.
- Harmony: color relationships should support the intended tone without competing for attention.
- Adaptability: color decisions should survive changes in brightness, environment, medium, and user preference.
- Priority: high-emphasis color should be reserved for high-importance meaning or action.

## Guidance

Color should clarify. If removing color destroys meaning, the design is relying on color too heavily.
