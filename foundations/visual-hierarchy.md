# Visual Hierarchy

## Question

How should attention be guided?

## Purpose

Visual hierarchy helps people understand what matters, where to begin, and what to do next.

## Principles

- Priority: the most important task or information should receive the strongest emphasis.
- Scan order: layout should support a predictable path through content and actions.
- Contrast: differences in size, weight, spacing, color, and position should signal meaningful differences.
- Grouping: related elements should read as a unit before individual details compete.
- Density: information density should fit the task, risk, frequency, and user expertise.
- Rhythm: repeated spacing and alignment should create visual cadence.
- Focus: avoid unnecessary attention competition between elements.
- Balance: hierarchy should guide attention without making secondary material disappear.

## Guidance

Hierarchy is not decoration. It is the visible structure of decision-making.
