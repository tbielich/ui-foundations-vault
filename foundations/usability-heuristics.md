# Usability Heuristics

## Question

How do we evaluate usability?

## Purpose

Usability heuristics describe recurring qualities of interfaces that are easy to understand, operate, and recover from.

## Heuristics

- Feedback: user actions should produce clear visible, structural, or assistive response.
- Consistency: similar things should behave, read, and respond in similar ways.
- Error prevention: structure should prevent avoidable mistakes before they happen.
- Recognition: interfaces should make options, context, and state visible instead of relying on memory.
- User control: people should understand current state, change reversible choices, cancel where appropriate, and recover from mistakes.
- Accessibility: interaction should remain usable through multiple input methods, assistive technologies, and perceptual conditions.
- Clarity: labels, actions, states, and outcomes should be unambiguous.
- Efficiency: frequent or important tasks should not require unnecessary effort.

## Guidance

Heuristics are lenses for review, not a replacement for user context. Apply them together with goal, audience, task frequency, risk, and environment.
