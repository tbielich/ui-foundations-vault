# Typography

## Question

How should text communicate?

## Purpose

Typography shapes how text is read, scanned, prioritized, and trusted.

## Principles

- Readability: text should be comfortable to read at the expected size, distance, and density.
- Hierarchy: type size, weight, spacing, and position should reveal importance and structure.
- Rhythm: line height and spacing should create a stable reading cadence.
- Economy: use typographic variation deliberately; too many styles weaken meaning.
- Separation of concerns: typography should express structure and emphasis, not replace semantic meaning.
- Accessibility: text should remain legible under zoom, contrast changes, language variation, and assistive reading conditions.
- Consistency: repeated text roles should look and behave consistently.
- Context fit: dense operational text, editorial text, labels, and instructions need different typographic treatment.

## Guidance

Good typography reduces effort. It should help people identify what to read first, what belongs together, and what action or decision the text supports.
