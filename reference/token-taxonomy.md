# Token Taxonomy

## Question

How are token concepts classified?

## Purpose

This document provides canonical lookup categories for token concepts in UI Foundations.

## Classes

- Core token: primitive reusable material without product or component meaning.
- Mode token: contextual variation that adapts primitive material to an environment.
- Theme token: brand-level interpretation of shared semantic structure.
- Semantic token: stable meaning exposed for reuse across local surfaces.
- Pattern token: local design decision for reusable composition.
- Component token: local design decision for a component surface, part, variant, or state.
- Status token: semantic token category for global meaning.
- State token: local token category for temporary interaction or condition.
