# Terminology

## Question

What terms are canonical in UI Foundations?

## Purpose

This document defines shared vocabulary for the vault. Definitions are concise lookup entries, not design guidance.

## Terms

- Architecture: the conceptual structure that explains how knowledge, decisions, and system parts relate.
- Component: a reusable UI building block with a distinct responsibility and stable public model.
- Core token: a primitive token that provides raw reusable material without product or component meaning.
- Design intelligence: contextual judgment beyond rule compliance.
- Foundation: immutable design knowledge that remains valid independent of UI Foundations implementation.
- Governance: rules for how vault knowledge is reviewed, trusted, changed, and retired.
- Mode: contextual variation such as appearance, density, contrast, or environment.
- Pattern: reusable composition intent for a recurring interface problem.
- Semantic token: a token that exposes stable design meaning.
- State: a temporary condition, interaction, or availability within a component.
- Status: global semantic meaning such as severity, success, or warning.
- Theme: brand-level interpretation of shared semantic structure.
- Token: a named design decision that can be referenced by higher-level knowledge.
