# Component Implementation Rules

## Rules

- Components should implement documented states, not only visual defaults.
- Public component behavior should map to documented component models and composition rules.
- Exceptions must be documented in the runtime repository.
- Reusable exceptions should be proposed back to the vault as lessons.
- Component code remains owned by the runtime repository.
